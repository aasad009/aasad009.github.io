# Layout fix and compatibility notes

The previous fossil/forest redesign overwrote structural CSS rules in Direction 2 and Direction 3. This package restores all of the demos' original CSS blocks (including their independent atlases, charts, responsive grids, and comparative experiment sections), then adds a narrowly scoped forest/paper visual theme at the end.

Direction 1 and the landing page retain the forest redesign and personal portrait. All JavaScript, science content, and embedded proposals are preserved.

For GitHub Pages, replace the entire existing `research-directions/` directory with the one in this archive. On a cached browser tab, reload with Ctrl+Shift+R.
