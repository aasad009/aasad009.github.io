# Reconstructing the Missing Mechanics of Evolution — website release

Deploy this `research-directions` folder at the root of the existing GitHub Pages repository. No backend, CDN or external JavaScript dependency is required. The original three demo solvers have been preserved.

## Release updates
- Landing page has the supplied pixel-sunglasses forest portrait, share-preview image, and three linked/parallel research cards.
- Three verified research publications are summarized with true benchmark scope and direct DOI links; they do not claim fossil validation.
- Muscle demo adds a specific Bishop–Pierce anatomical homology reference (triceps coracoideus / dorsoepitrochlearis), but deliberately keeps its 2D generated muscle paths synthetic.
- Joint demo brings the evolving scientific interpretation next to the 3D hip and labels non-calibrated tissue priors.
- Spine demo cites the real 2024 comparative biological finding and Dryad data, separate from its synthetic coupled-column simulation, with explicit null/restore controls.
- Added on-page proposal contents navigation and social link-preview metadata.

## Critical scientific limitations
**None of the interactive models has been calibrated against actual fossil muscle anatomy or measured evolutionary transitions.** The osteological homology case is literature-grounded; the drawn geometry is not. The spine biological comparison is literature-grounded, while its displayed numerical stiffness and rotations are generated by the illustrative reduced-order model.

## User upload/deployment
Extract the ZIP. Upload `research-directions/` to the repository root, replacing the existing folder; keep other website files unchanged. Open the link after deployment and hard refresh. Check that the GitHub Pages custom-domain configuration remains unaffected.
