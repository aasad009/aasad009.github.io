### Rainforest soundtrack (all four pages)
The soundtrack is enabled by default on the landing page and all three proposal/demo pages, with an always-visible mute control. Preferences are remembered across pages; the position in the 32-second loop is restored on navigation. Modern browsers may restrict audible autoplay until the first click, tap or keypress. If the initial playback request is denied, the page retries on the first interaction; the visible sound button can also start it. Muting persists across navigation. For consistent audio, upload both assets/rainforest-audio.js and assets/rainforest-audio.css along with the existing ambience MP3.
